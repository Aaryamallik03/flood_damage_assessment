Building Damage Assessment from Pre- and Post-Flood Imagery

A Siamese ResNet-50 model compares corresponding pre- and post-disaster building imagery and classifies damage as no damage, minor, major, or destroyed. This research prototype was trained on xBD flood imagery and has not yet been independently validated on Nepal flood imagery.

01

Method

The building classifier uses a Siamese convolutional neural network with two branches that share the same ResNet-50 encoder weights. Each branch converts one image into a 2048-dimensional feature representation.

  1. Extract a building-centered patch from the pre-disaster image.
  2. Extract the same spatial region from the post-disaster image.
  3. Encode both patches using the shared ResNet-50.
  4. Concatenate the two feature vectors.
  5. Classify the resulting representation into four damage classes.
Second component: a SAR-based flood extent segmentation pipeline is also under development. It is not yet evaluated on a properly held-out dataset.

04

Dataset

The building damage component uses flood-related events from the xBD / xView2 disaster-damage dataset. Building-centered pre- and post-disaster image patches are extracted from corresponding spatial locations.

No damage 23,424
Minor damage 9,360
Major damage 10,302
Destroyed 2,623

Images are resized to 224 × 224 and normalized using ImageNet statistics. The class distribution is imbalanced, with destroyed buildings representing the smallest class.

05

Nepal evaluation

Nepal is an important potential evaluation setting for this project because flood and landslide events can produce substantial structural damage while presenting imagery that differs from the events used during training.

The August 2026 Nepal flood event provides a relevant real-world setting for investigating whether a model trained on xBD imagery can generalize to a different geographic and disaster distribution.

Generalization warning: The classifier was trained on other flood events in xBD. Nepal imagery may differ in geography, building structure, image acquisition conditions and damage patterns. Predictions on Nepal imagery should therefore be treated as experimental model outputs, not verified damage assessments.

A future evaluation can compare predictions on individual building footprints against independently generated labels, published damage maps or field assessments.

06

Limitations

  • No independent, event-level test set has been established yet.
  • The original training process used a random train/validation split, so related imagery can potentially appear across different splits.
  • Building-centered crops must be supplied; automatic building detection is not currently implemented.
  • The SAR flood segmentation component has not been evaluated on held-out data.
  • The model has not been independently validated for Nepal or another completely unseen geographic event.
  • The system should not be used as the sole basis for rescue, insurance, infrastructure, or other high-stakes decisions.
07

Next steps

  • Introduce reproducible event-level train, validation and test splits.
  • Evaluate generalization on completely unseen disaster events.
  • Validate performance on Nepal-specific flood imagery.
  • Add automatic building-footprint detection for inference.
  • Improve handling of the imbalanced damage classes.
  • Evaluate and improve the SAR flood segmentation component.
  • Add calibrated probabilities and additional error analysis.
  • Explore Grad-CAM or related explainability methods.
